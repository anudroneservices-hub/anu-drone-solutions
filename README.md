# Anu Drone Solutions Website

A static marketing website for Anu Drone Solutions, built for quick deployment on GitHub Pages, Netlify, Vercel, or any static hosting provider.

## Pages
- `index.html`
- `services.html`
- `gallery.html`
- `contact.html`

## Live deployment checklist
1. Upload the project folder to your static host.
2. Ensure the root path serves the site as the homepage.
3. Update the domain and canonical URLs if the live site uses a different hostname.
4. Confirm the mailto form works in the browser on the live domain.
5. Verify the YouTube and contact links are correct.

## Notes
- The contact form opens the visitor's default email client with a pre-filled quote request.
- The site is fully static and requires no build step.
- Replace the placeholder live URLs if you plan to use a custom domain different from `https://www.anudronesolutions.com`.
